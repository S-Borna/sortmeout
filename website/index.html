Features

Everything you need to
automate your files

Powerful features wrapped in a simple, intuitive interface. Set up rules once and let SortMeOut handle the rest.

Smart Rules

Create powerful rules with flexible conditions. Match files by name, extension, size, date, tags, and more.

Real-Time Monitoring

Watch folders in real-time using native macOS file events. Files are processed instantly as they appear.

Finder Tags

Full integration with macOS Finder tags. Add, remove, or organize files based on color tags and labels.

Smart Trash

Intelligent trash management with automatic cleanup. Set rules to empty trash based on file age.

App Sweep

Clean up app remnants when uninstalling. Finds and removes leftover preferences, caches, and support files.

CLI & Scripting

Full command-line interface and shell script support. Automate workflows and integrate with other tools.

Spotlight Search

Leverage macOS Spotlight for advanced file searches. Find files by content, metadata, and more.

Preview Mode

Test your rules safely before applying them. See exactly what would happen without making changes.
